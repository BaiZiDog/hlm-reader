# 隐私说明

## 阅读与本地数据

- 阅读、搜索、注释跳转、缩放和进度保存都在本机完成，不发送到本项目。
- 桌面版阅读进度、缩放和窗口位置保存在 `%APPDATA%\红楼梦阅读器\reader-state.json`。
- 移动端阅读进度、偏好保存在浏览器 `localStorage`；导入的书页保存在 IndexedDB。
- PWA 的 Service Worker 只缓存同源界面与书源文件，不缓存 AI 请求。

## AI 导读

只有在你主动使用 AI 导读时，才会发送数据：

- 你输入的提问；
- 当前阅读位置、防剧透状态；
- AI 为回答而读取的章节正文与本章注释；
- 可选的隐藏背景信息文件（如果存在）；
- 对话历史（用于多轮上下文）。

这些内容会发送到你在设置中选择的 AI 服务：

- **桌面内置免费模型**：请求经本机 `127.0.0.1` 的 Our Free Model 服务转发到 Kilo、OpenRouter 等免费模型上游。免费池的提示词可能被上游记录。
- **自定义 / Anthropic 官方 API**：内容直接发送到你填写的 Base URL 对应服务，适用该服务自己的隐私政策。

请勿在提问、书源或背景信息中放入密钥、个人信息或其他敏感内容。

## API Key

- **桌面版**：自定义 API Key 用 Electron `safeStorage`（Windows DPAPI）加密后保存在本机；内置服务的内部 Key 只在本机生成，不返回渲染进程。
- **移动 / PWA 版**：没有系统级密钥存储，API Key 保存在本机浏览器 `localStorage`，不会上传到本项目。请只在个人设备使用；公共设备上建议用完后在 AI 设置中删除密钥。

## 网络

阅读器不会主动上报统计、崩溃或使用数据，也没有账号系统。除了 AI 请求、可选的 PWA 更新检查和你配置的 API 之外，不连接其他服务器。

## 删除数据

- 桌面：删除 `%APPDATA%\红楼梦阅读器`。
- 移动端：在浏览器设置中清除该站点的数据，或删除已安装的 PWA 数据。
